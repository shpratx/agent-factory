# Example evaluation task

## Task definition

Task name: Customer support response quality
Description: Evaluate whether a support agent response is accurate, empathetic, complete, and compliant.
Success criteria:
- Response addresses the user request directly
- Response is concise and empathetic
- Response does not invent policies or facts
Failure modes:
- Hallucinated refund policy
- Missing empathy
- Overly verbose response
Output type: text
Difficulty: medium
