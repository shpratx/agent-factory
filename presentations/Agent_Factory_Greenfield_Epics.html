Agent Factory Reference — Greenfield Extension

Build Epics — Agentic-AI CoE Backlog

Each of the 35 agents in Agent_Factory_E2E_SDLC_Diagram_Greenfield.html, reverse-engineered into the raw business requirement that would justify building it. Epic title = the requirement. "Realizes Agent" = the traceability link back to the diagram/BOM/requirements/workflow docs.

How to read this: these are epics for the Agentic-AI CoE's own backlog — the team building the Agent Factory itself, not the Feature Cell using it. "Depends On" is the build-order dependency between epics (which agent's output another agent needs to exist first), computed the same way L1-planning-dependency-mapper would compute it for any other backlog — applied here reflexively to the meta-work of building the pipeline. Acceptance criteria are condensed from the full FR list in Agent_Factory_Greenfield_Requirements.html; that document is the source of truth for Definition of Done.
